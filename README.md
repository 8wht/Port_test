# Portfólio

Tela inicial cinematográfica para um portfólio pessoal, criada com HTML, CSS e JavaScript. A introdução começa com uma corrente de plasma em Canvas e transiciona para um vídeo em tela cheia, com tipografia, controles e progresso sincronizado.

## Executar localmente

Abra o arquivo `index.html` no navegador ou use um servidor estático local.

## Estrutura

- `index.html`: conteúdo da tela inicial
- `style.css`: layout, cores e animações
- `script.js`: plasma em Canvas, transições e controles do vídeo
- `shot_01.mp4`: vídeo principal da introdução
